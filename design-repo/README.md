# Dualite Claims clone: design-repo

A machine-validated design-repo (tokens, primitives, components, section contracts, one page
template, compatibility graph, Draft-07 PageSpec schema, semantic validator, adversarial and
drift proofs) extracted from the Dualite Claims clone, which rebuilds
`https://claims.dualite.dev/` as a single long page.

Status: `design-review-pending`, `productionApproved: false`.

> **Sensitivity.** The source is a real, live company site (Dualite / Dualite Claims / ClaimIt by
> Dualite). Its brand, logos, product screenshots, customer testimonial video, customer names,
> quotes, results, copy and URLs belong to the company or its customers. Do not publish this
> package. Generated pages (`mode: "generated"`) are mechanically blocked from reproducing any of
> it, and the source's demo form posts to a live lead endpoint that must never be submitted.

## Page shape

`template.home` (route `/`) is the only page shape the clone serves. Node order is the measured DOM
order (`src/App.jsx:35-63`):

| Region | Sections (semantic id, category) |
|---|---|
| pre-main | `utility.skip-link` UTILITY, `runtime.intro-loader` RUNTIME (optional), `utility.scroll-progress` UTILITY, `utility.grain-overlay` UTILITY (optional), `shell.navbar` SHELL, `runtime.mobile-menu` RUNTIME |
| main | `hero.claims-intro` HERO, `proof.quote-logos` SOCIAL_PROOF, `content.problem-costs` PROBLEM, `metrics.results-band` METRICS, `features.pinned-workflow` FEATURES, `product.demo-walkthrough` PRODUCT_DEMO, `features.platform-tabs` FEATURES, `trust.guarantees` TRUST, `features.reconciliation` FEATURES, `proof.video-story` SOCIAL_PROOF, `editorial.case-study` EDITORIAL, `faq.accordion` FAQ, `conversion.demo-form` CTA_CONVERSION |
| post-main | `shell.footer` FOOTER |

Category notes (R6): the demo-booking form is CTA_CONVERSION; the video story and the quote strip
are SOCIAL_PROOF; the case study is EDITORIAL; FEATURES is reserved for capabilities/workflows.
Sections are semantic units: the hero is 900px at 1440 (only the opening composition), and the
tallest in-flow section, the pinned workflow, measures 5580px including its 4680px pin spacer,
31.7% of the page, under the 50% share warning, so no wrapper whitelist entry is needed.

Routes (R11): `/` is implemented. `/blog/` and the three `/blog/*-claim-submission-guide/` links
exist on the live site, but the clone does not implement them (its dev server answers with the
SPA homepage, a soft 404). They are recorded in `templates/routes.json` as not implemented by the
clone, so the blog/article family has no template. The clone omits it; this repo did not drop it.

## The intro loader (load screen)

`sections/runtime.intro-loader.json` is a full contract, with `retrievalEligible: false` (it is a
preloader and never retrieved as content). Motion pattern `intro-loader-seal` lives in
`tokens/00-foundation/motion-patterns.json`.

- **Structure:** a fixed full-viewport overlay (z 150, paper surface, padding 28px gutter) with a
  top row (brand label + file tag; mono 11px, .14em, uppercase, muted). The centre holds a 132px
  olive seal SVG: an ink disc r62 (opacity 0 -> .12), drawn circles r62/r38, ring text on a
  `textPath` (textLength 292) and a drawn check `M52 67l10 10 20-22`. Below it sits the status
  line (mono 12px olive). The bottom row has the 00 -> 100 counter (display face,
  clamp(64px,9vw,128px), lh .8) and a foot label. A 2px olive progress bar runs along the bottom.
  Six night-coloured panels perform the exit wipe.
- **Timeline** (anime.js 4 timeline, T0 = `html.is-ready` after fonts + triggers): seal draw
  0-1250ms (stagger 160, inOut(3)). Counter + bar 0-1750ms (inOut(2)), with status steps at 22 /
  48 / 74 / 96. Ring text fades in at 850ms (600ms). Stamp at 1650ms: scale [1,.9,1.02,1],
  rotate -8deg. Ink at 1700ms. Panels scaleY 0 -> 1 at 2050ms (650ms, stagger 55, inOut(4)). At
  2780ms the content is hidden, the background goes transparent and the hero intro starts. Panels
  translateY 0 -> -101% at 2800ms (800ms, stagger 55). At 3700ms the loader gets
  `display:none`, smooth scroll restarts and `sessionStorage dc-intro=1` is set.
- **Measured** (live, absolute ms): is-ready 1134, status changes 1711 / 1981 / 2253 / 2641,
  panels start 3211, background transparent 3943, panels off 4711, display none 4843. The clone
  is offset by its earlier is-ready (815ms). Raw logs are in `extraction/measured-values.json`
  under `loader`.
- **Gating:** plays once per session (`dc-intro`). It is skipped under
  `prefers-reduced-motion: reduce`. A 6000ms head-script safety net shows the page if `is-ready`
  never arrives. It is hidden without JS.
- **Generation-safe variant** (in `schema/examples/home.generated.pagespec.json`): fictional brand
  label, placeholder file tag, generic ring text, and `mark.seal-generic` instead of the source
  seal. The adversarial suite rejects the source strings ("DUALITE CLAIMS · CHECKED · SEALED ·
  FILED ·", "Claim 1187 · RGHS · OPD", "ECHS · RGHS · OPD · IPD", "Opening claim file", "Checking
  50+ case rules") and the source seal mark.
- **Correction:** the brief described the loader seal as drawn with GSAP DrawSVG. The real
  `loader()` uses anime.js (`A.svg.createDrawable`); DrawSVG is used for the results arrows.

Other retrieval-ineligible runtime UI: skip link, scroll progress, grain overlay, mobile menu drawer
(sections), and form submit feedback (`components/form-feedback.json`). The ineligible set is
pinned in both `schema/semantic_validate.py` and `extraction/verify_all.py`.

## Modes and generation rules

Every PageSpec declares `mode`:

- `reference` is a faithful reconstruction: real brand, copy and assets are allowed as evidence.
- `generated` is a new page for someone else. The validator rejects `GENERATED_MODE_BRAND`, `_CTA`,
  `_COPY` (exact strings of 3+ words and 5-word shingles against the real source corpus), `_URL`
  (only `#anchors` and reserved `.example` / `.invalid` domains), `_ASSET` (pinned availability +
  source filenames + live endpoint), `_PERSON` (real people/customers; fictional people must be
  flagged), and `_RATING` (source results such as 48%, 66%, 7 -> 3 days, ₹ figures, 50+ case rules).

Patterns live in `schema/source-brand.json` and were taken from the real source. Asset availability
is `reference-only`, `generation-safe` or `blocked-for-generation`. It is pinned in code, so
editing the registry alone fails validation.

Token overrides: `node.style` (surface / accent / text / paddingBlock / displayFont) accepts catalog
ids only. Raw colours, raw lengths, unknown fonts, unknown ids, wrong categories and wrong
theme/token combinations are rejected (`tokens/llm/token-policy.json`).

## Verify

```bash
python3 extraction/verify_all.py                 # all consistency, citation, pin, parity, gate checks
python3 schema/semantic_validate.py schema/examples/*.pagespec.json
python3 schema/tests/adversarial_test.py         # every mutation rejected, every control passes
python3 extraction/prove_drift.py                # verify_all proven to catch injected drift
python3 extraction/wrapper_gate.py               # R9 height gate on measured 1440px heights
python3 schema/generate_schema.py --write        # after editing a section contract
python3 extraction/token_catalog.py --write      # after editing a token file
python3 extraction/verify_all.py --write-counts  # after adding/removing files
```

Requires Python 3.9+ and `jsonschema` (Draft-07). The Node tools (`measure_sections.mjs`,
`parity_harness.mjs`) are optional. Point `PLAYWRIGHT_MODULE` at a Playwright install. When this
folder is copied out on its own, the citation re-reads warn instead of failing. Pass
`--source-root <clone project>` to re-enable them.

## Clone quality evidence (R12)

`extraction/parity_harness.mjs` ran on 2026-10-27, live site vs the clone dev server, at 1440x900
under deterministic conditions: reduced motion, intro marked seen, animations off, grain/nav
hidden, videos paused. The per-section pixel match is in `extraction/measured-values.json ->
parity`: every section scored 99.93-100%, average 99.99%, gate (every section >= 80%) passed. A
negative control comparing two different sections scored 1.92%. Mobile (375) was compared
structurally (identical section boxes, docHeight 21028 on both), not pixel-diffed. All 77
ScrollTriggers and the single pin (2888 -> 7568, scrub 0.9) match.
